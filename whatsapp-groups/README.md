# קבוצות WhatsApp — סצנת מושן גרפיקס (16:9, עברית)

<div dir="rtl">

סצנה של ‎1920×1080, ‏30fps, באורך 1:44 דקות. קבוצה חדשה נפתחת במסך מלא ומופיעה הודעת מערכת שמישהו הוסיף אותך. אחר כך מתחילה התכתבות, וקבוצות נוספות מצטרפות ומפצלות את המסך לשתיים, שלוש ולבסוף ארבע. כל הקבוצות ממשיכות להתכתב במקביל, והמיקוד עובר ביניהן: הקבוצה שבמיקוד רחבה וגדולה יותר, והאחרות מעומעמות וממשיכות ברקע.

**הסרטון המוכן:** `output/whatsapp-groups.mp4`

## מבנה

| קובץ | תפקיד |
|---|---|
| `data/scene.js` | **כל התוכן העריך:** משתתפים, הודעות, תגובות, קבצים, שעות, ציר זמן (הצטרפות, מיקוד, גלילות) ופריסה |
| `index.html` | תצוגה מקדימה עם נגן. פותחים ישירות בדפדפן, בלי שרת |
| `src/engine.js` | המנוע: בונה את ממשק WhatsApp ומצייר כל פריים באופן דטרמיניסטי לפי הזמן |
| `src/styles.css` | עיצוב הממשק (מידות ב־dp של אנדרואיד) |
| `src/art.js` | אייקונים, תמונות פרופיל מאוירות, תמונות קבוצה וטפט הדודלים, הכול בקוד SVG |
| `render.mjs` | רינדור ל־MP4 באמצעות Chromium ו־ffmpeg |
| `assets/fonts` | ‏Roboto ו־Noto Sans Hebrew (הגופנים של WhatsApp באנדרואיד, רישיון OFL) |

## תצוגה מקדימה

פותחים את `index.html` בכרום. רווח מפעיל ועוצר, החצים קופצים שנייה קדימה או אחורה, והתפריט מאפשר לקפוץ לרגעי הצטרפות ומיקוד. אפשר לפתוח ישירות בזמן מסוים עם `index.html?t=45`.

## רינדור

דרוש Node 18 ומעלה, וגם `ffmpeg` ב־PATH.

```bash
npm install
npx playwright-core install chromium   # רק אם אין כרומיום מותקן (או CHROME_PATH=/path/to/chrome)
npm run render                          # → output/whatsapp-groups.mp4
npm run render:60                       # גרסת 60fps
node render.mjs --from 40 --to 60       # קטע בלבד
node render.mjs --stills 12,50,90       # תמונות סטילס ל־output/stills
```

הרינדור לוקח כ־2.5 דקות ב־4 תהליכים מקבילים (`--workers`). אפשר לשנות את האיכות עם `--crf` (ברירת המחדל 16).

## עריכה (`data/scene.js`)

- **טקסטים:** עורכים את `text` בכל הודעה. הודעות מערכת: `{ type: 'system', text }`.
- **טיימינג:** לכל הודעה יש `at` (שניות מתחילת הסרטון). "מקליד/ה…" מופיע בכותרת כ־1.3 שניות לפני ההודעה (אפשר לשנות עם `typing`). השעה בבועה מחושבת אוטומטית מ־`clock`, או נקבעת ידנית עם `time: '10:31'`.
- **משתתפים:** לכל קבוצה יש `participants`.
  - איש קשר שמור: `{ saved: true, name, color, avatar }`. בראש הבועה מוצג השם בצבע.
  - לא שמור: `{ phone, pushName, color, avatar }`. בראש הבועה מוצג המספר בצבע, ובצד השני "~שם פרופיל" באפור.
- **תשובה מצוטטת:** `reply: '<id>'` מצטט הודעה קודמת עם אותו `id`.
- **תגובות:** `reactions: [{ at, emojis: ['❤️','👍'], count: 3 }]`. כל רשומה מחליפה את מצב התגובה בזמן שלה.
- **קבצים וכרטיסים:** `file: { kind: 'pdf' | 'doc', name, pages, size }` או `card: { title, subtitle, art }`. ה־`text` של ההודעה מוצג ככיתוב.
- **ציר זמן:** `timeline.joins` קובע מתי כל קבוצה נכנסת, `timeline.focus` מתי כל קבוצה במיקוד (`group: null` = כולן שוות), ו־`timeline.scrolls` קובע גלילה אל הודעה קודמת עם הדגשה וחזרה למטה (`tapReply` מוסיף "לחיצה" על ציטוט לפני הגלילה).
- **פריסה:** ב־`layout` נקבעים השוליים, הרווחים, עוצמת העמעום, משך המעברים, כמה רחבה הקבוצה שבמיקוד (`focusBoost`) ועקומת ההגדלה של הממשק (`scaleCurve`).

אחרי עריכה מרעננים את `index.html` כדי לבדוק, ומריצים `npm run render`.

## הערות

- **RTL:** הממשק מראה את WhatsApp לאנדרואיד בעברית. הודעות נכנסות בצד ימין עם הזנב בפינה הימנית העליונה, השעה בפינה השמאלית התחתונה, הפס הצבעוני של ציטוט בצד ימין, תגובות בצד ימין למטה, חץ החזרה פונה ימינה, וכפתור המיקרופון בצד שמאל.
- **מספרים:** מספרי טלפון, תאריכים וטווחים מבודדים בכיוון LTR, כך שהם מוצגים נכון בתוך טקסט עברי (למשל ‎`+972 54-731-2289`, ‎`12–14.11.2026`). שמות ארוכים מקוצרים עם "…" בסוף המחרוזת, כמו באנדרואיד.
- **מסמכים:** התצוגה המקדימה של קובצי ה־PDF וכרטיסי המידע מופשטת (פסים אפורים ואיור), בלי תוכן תפעולי. שמות הקבצים נגזרים מטקסט ההודעה.
- **הודעות מערכת:** הטקסטים נשמרו כפי שנכתבו בתסריט. ב־WhatsApp אמיתי, כשמי שהוסיף אותך לא שמור באנשי הקשר (טל, אלון), הודעת המערכת מציגה את המספר שלו. אם רוצים את ההתנהגות הזו, מחליפים את הטקסט ב־`scene.js`.
- **אימוג'י:** מוצגים בגופן Noto Color Emoji של המערכת. רינדור במחשב אחר עשוי להציג אימוג'י בסגנון מעט שונה.
