# קבוצות WhatsApp — סצנת מושן גרפיקס (16:9, עברית)

<div dir="rtl">

קליפ שיווקי של ‎1920×1080, ‏60fps, באורך 15 שניות. הוא נפתח בטלפון אחד ממורכז, שבו מופיעה הודעת מערכת שמישהו הוסיף אותך לקבוצה, ומיד מתחילה התכתבות. בשניות 3.2, ‏6.2 ו־9.2 טלפון חדש עם קבוצה נוספת עולה מלמטה משמאל, והשורה כולה מתמרכזת מחדש: שניים, שלושה ולבסוף ארבעה טלפונים. אין קבוצה במיקוד, וכל הקבוצות ממשיכות להתכתב יחד.

**הקצב:**
- ההודעות מתחלפות בין הטלפונים: בערך הודעה כל 0.3 שניות במסך כולו, וכל 1.2 שניות בכל טלפון.
- כניסה של קבוצה חדשה היא רגע שקט, שבו שאר הטלפונים לא מקבלים הודעות.
- בשנייה האחרונה מופיעות רק תגובות, כך שיש נקודה נוחה לחתוך או לעבור ממנה לסצנה הבאה.

**קבוצות עם שיחה קיימת:**
- גליל וים המלח נפתחות ריקות, עם הרגע של "X הוסיף אותך לקבוצה".
- אילת ווינה נכנסות כשכבר יש בהן שיחה (הודעת המערכת ואחריה 3–4 הודעות), כמו קבוצה שצורפת אליה קצת קודם, ואז ממשיכות לקבל הודעות חדשות.
- כדי שהודעה תופיע מראש, נותנים לה `at` שקודם לזמן הכניסה של הקבוצה.

**תנועה יציבה:**
- התנועות רכות ובלי קפיצה מעבר ליעד.
- הטלפונים לא מרחפים, ואין זום רציף של מצלמה.
- כל טלפון הוא שכבה נפרדת שזזה בתת־פיקסלים, ובמנוחה הוא עומד על מיקום שלם.
- הרינדור נעשה ברזולוציה כפולה ומוקטן ל־1080p, כדי שטקסט בתנועה לא ירצד.

גרסאות קודמות שמורות בהיסטוריה של git: הגרסה של 1:44 דקות (מסך מפוצל עם מיקוד) בקומיט `1ff6535`, וגרסת 12 השניות בקומיט שאחריו.

**הסרטון המוכן:** `output/whatsapp-groups.mp4`

## מבנה

| קובץ | תפקיד |
|---|---|
| `data/scene.js` | **כל התוכן העריך:** משתתפים, הודעות, תגובות, קבצים, שעות, ציר זמן (הצטרפות, מיקוד, גלילות) ופריסה |
| `index.html` | תצוגה מקדימה עם נגן. פותחים ישירות בדפדפן, בלי שרת |
| `src/engine.js` | המנוע: בונה את הטלפונים ואת ממשק WhatsApp, ומצייר כל פריים באופן דטרמיניסטי לפי הזמן |
| `src/styles.css` | עיצוב הממשק (מידות ב־dp של אנדרואיד) |
| `src/art.js` | אייקונים, תמונות פרופיל מאוירות, תמונות קבוצה וטפט הדודלים, הכול בקוד SVG |
| `render.mjs` | רינדור ל־MP4 באמצעות Chromium ו־ffmpeg |
| `assets/fonts` | ‏Roboto ו־Noto Sans Hebrew (הגופנים של WhatsApp באנדרואיד, רישיון OFL) |

## תצוגה מקדימה

פותחים את `index.html` בכרום. רווח מפעיל ועוצר, החצים קופצים שנייה קדימה או אחורה, והתפריט מאפשר לקפוץ לרגעי הצטרפות ומיקוד. אפשר לפתוח ישירות בזמן מסוים עם `index.html?t=45`.

## רינדור

דרוש Node 18 ומעלה, וגם `ffmpeg` ב־PATH.

```bash
npm install
npx playwright-core install chromium   # רק אם אין כרומיום מותקן (או CHROME_PATH=/path/to/chrome)
npm run render                          # → output/whatsapp-groups.mp4 (60fps)
node render.mjs --fps 30 --out output/whatsapp-groups-30fps.mp4   # גרסת 30fps
node render.mjs --from 4 --to 8         # קטע בלבד
node render.mjs --stills 1,5,11.9       # תמונות סטילס ל־output/stills
```

הרינדור לוקח כדקה וחצי ב־3 תהליכים מקבילים (`--workers`). אפשר לשנות את האיכות עם `--crf` (ברירת המחדל 16). דגימת־היתר מוגדרת ב־`--ss` (ברירת המחדל 2; הערך 1 מהיר יותר, אבל הטקסט ירצד יותר בתנועה).

## עריכה (`data/scene.js`)

- **טקסטים:** עורכים את `text` בכל הודעה. הודעות מערכת: `{ type: 'system', text }`.
- **טיימינג:** לכל הודעה יש `at` (שניות מתחילת הסרטון). שורות מהתסריט שלא נכנסו לקליפ מופיעות בהערה בסוף כל קבוצה, ואפשר להחזיר אותן עם זמן משלהן. "מקליד/ה…" מופיע בכותרת רק כשיש רווח של שנייה ומעלה מההודעה הקודמת באותה קבוצה (אפשר לשנות עם `typing`). השעה בבועה ובשורת הסטטוס מחושבת אוטומטית מ־`clock`, או נקבעת ידנית עם `time: '10:31'`.
- **משתתפים:** לכל קבוצה יש `participants`.
  - איש קשר שמור: `{ saved: true, name, color, avatar }`. בראש הבועה מוצג השם בצבע.
  - לא שמור: `{ phone, pushName, color, avatar }`. בראש הבועה מוצג המספר בצבע, ובצד השני "~שם פרופיל" באפור.
- **תשובה מצוטטת:** `reply: '<id>'` מצטט הודעה קודמת עם אותו `id`.
- **תגובות:** `reactions: [{ at, emojis: ['❤️','👍'], count: 3 }]`. כל רשומה מחליפה את מצב התגובה בזמן שלה.
- **קבצים וכרטיסים:** `file: { kind: 'pdf' | 'doc', name, pages, size }` או `card: { title, subtitle, art }`. ה־`text` של ההודעה מוצג ככיתוב.
- **ציר זמן:** `timeline.joins` קובע מתי כל קבוצה נכנסת למסך.
- **טלפונים:** ב־`phones` נקבעים הגודל, הרווח, עובי המסגרת, רוחב הממשק ב־dp (קטן יותר = טקסט גדול יותר), משך הכניסה ועוצמת הריחוף.
- **מצלמה:** `camera.zoomByCount` קובע את הזום לפי מספר הטלפונים על המסך. הזום כבוי כרגע (ערך 1), כי זום רציף גורם לטקסט לרצד בסוף כל תנועה.
- **אפקטים:** ב־`effects` אפשר לכבות או לכוונן את ההילה בכניסה (`joinGlow`), האימוג'ים שעפים מתגובות (`reactionBursts`, כבוי כרגע), משך הכניסה של הודעה ו"מקליד/ה…".

אחרי עריכה מרעננים את `index.html` כדי לבדוק, ומריצים `npm run render`.

## הערות

- **RTL:** הממשק מראה את WhatsApp לאנדרואיד בעברית. הודעות נכנסות בצד ימין עם הזנב בפינה הימנית העליונה, השעה בפינה השמאלית התחתונה, הפס הצבעוני של ציטוט בצד ימין, תגובות בצד ימין למטה, חץ החזרה פונה ימינה, כפתור המיקרופון בצד שמאל, ובשורת הסטטוס השעון מימין. סדר הטלפונים גם הוא מימין לשמאל: הקבוצה הראשונה מימין, וכל חדשה נכנסת משמאל.
- **שמות קבוצות:** בטלפון ברוחב רגיל שם הקבוצה ארוך מדי, ולכן הוא מקוצר עם "…" כמו באפליקציה (היעד נשאר גלוי, התאריכים נחתכים).
- **מספרים:** מספרי טלפון, תאריכים וטווחים מבודדים בכיוון LTR, כך שהם מוצגים נכון בתוך טקסט עברי (למשל ‎`+972 54-731-2289`, ‎`12–14.11.2026`). שמות ארוכים מקוצרים עם "…" בסוף המחרוזת, כמו באנדרואיד.
- **מסמכים:** התצוגה המקדימה של קובצי ה־PDF וכרטיסי המידע מופשטת (פסים אפורים ואיור), בלי תוכן תפעולי. שמות הקבצים נגזרים מטקסט ההודעה.
- **הודעות מערכת:** הטקסטים נשמרו כפי שנכתבו בתסריט. ב־WhatsApp אמיתי, כשמי שהוסיף אותך לא שמור באנשי הקשר (טל, אלון), הודעת המערכת מציגה את המספר שלו. אם רוצים את ההתנהגות הזו, מחליפים את הטקסט ב־`scene.js`.
- **אימוג'י:** מוצגים בגופן Noto Color Emoji של המערכת. רינדור במחשב אחר עשוי להציג אימוג'י בסגנון מעט שונה.
